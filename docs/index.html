The tool

The real thing, running right here.

This is the background remover from the repository itself — ONNX Runtime Web driving the U²-Net model, entirely on your device. Drop a photo into the frame below, or open the tool on its own page if you would rather have it full screen.

How it works

Three steps, none of them a sign-up form.

The heavy lifting is a segmentation network running in your browser tab. The first run downloads the model once (4.5 MB for the default); after that it is cached and every photo takes a second or two.

Step 01

Drop the photo

Drag it onto the card, click to browse, or paste a screenshot straight from the clipboard. PNG, JPG and WebP all work.

Step 02

The model finds the subject

U²-Net or ISNet predicts a soft alpha matte — a per-pixel mask, not a crude rectangle. Hair and thin edges survive.

Step 03

Pick a background, download

Keep it transparent, flatten onto a colour, blur the original, or drop the subject in front of your own image. Then save.

What you get

Small tool, no missing pieces.

True transparency

A real alpha channel in a PNG or WebP — not white pixels pretending to be empty.

Solid & brand colours

Flatten onto white, ink, or any hex value you type in. Ideal for catalogue and ID photos.

Blur the original

Keep the scene behind the subject but throw it out of focus — the portrait-mode look, done locally.

Custom backdrop

Composite the cutout onto a studio shot, a texture or a flat brand panel — one click in the local app.

Edge control

Feather smooths a jagged cut; grow and shrink pull a halo in or push a chewed edge back out.

Crop to subject

Trims the empty canvas away, with padding you control, so the cutout fills the frame.

Batch queue

Drop a whole folder and it queues up — one bad file reports itself and the rest keep going.

Export your way

PNG for transparency, JPG for size, WebP for both — with a quality control for the lossy two.

Model choice

Four models, one honest trade-off.

Bigger models are sharper on awkward subjects and slower to run. The default is small enough for a laptop with a browser full of tabs.

ModelDownloadBest for
u2netp default4.5 MBFast general use — people and products, a few hundred MB of RAM
u2net176 MBSharper edges when you have the time and ~1.5–2 GB of free RAM
isnet-general-use170 MBBest all-rounder for awkward subjects: hair, fur, thin straps
silueta43 MBSmall and quick, decent on people
Privacy by architecture

Your images never leave your device.

Not "we delete them after 24 hours" — they are never sent anywhere in the first place. The model arrives once, the pixels stay in the tab, and the download is generated by your own machine.

  • No server round-trip for your photos
  • No accounts, API keys or credits
  • No watermark on the output
  • Works offline once the model is cached
For power users

Need batch folders and a command line?

There is a local version of the same tool: a drag-and-drop app plus a CLI, with background-image replacement, model choice and folder-wide processing. Python 3.9 or newer.

terminal — install
# one command, that is the whole setup
pip install "rembg[cpu]" pillow

# then start the local web app
python bg_remover_app.py
# opens http://127.0.0.1:8000
terminal — command line
# transparent PNG next to the original
python bg_remove.py photo.jpg

# brand colour, trimmed to the subject
python bg_remove.py photo.jpg -o cut.png \
  --bg color --bg-color "#0f172a" --crop

# a whole folder, white background
python bg_remove.py photos/ -o cutouts/ \
  --bg color --bg-color white
FlagWhat it does
-m, --modelu2netp (default), u2net, isnet-general-use, silueta
--bgtransparent, color, image, blur
--bg-colorA colour name, #rrggbb, or r,g,b
--bg-imageYour own backdrop when --bg image is set
--featherEdge softening in pixels — default 1, 0 for a hard edge
--growGrow the subject edge (+) or shrink it (-), in pixels
--crop, --crop-paddingTrim the canvas to the subject, with padding as a fraction
--max-sizeDownscale so the longest side is at most N px — big speed-up on huge photos
--format, --qualitypng / jpg / webp, plus quality for the lossy ones
--suffixNaming for batch outputs — default _nobg
Questions

The things people ask before the first drop.

Is my photo uploaded anywhere?

No. The segmentation model is fetched once and then runs inside the browser tab. Your image is read from disk by the page itself and never leaves the device — there is no upload endpoint to send it to.

Why is the first image slow?

The model has to download on first use — 4.5 MB for the default u2netp. After that it is cached and a photo takes roughly one to three seconds.

What if my browser cannot run it?

It needs WebAssembly and a reasonably current Chrome, Edge, Firefox or Safari. If the model fails to load, use the local version: pip install "rembg[cpu]" pillow then run the app or the CLI.

Hair, fur and thin straps come out ragged. Can I fix that?

Try the isnet-general-use model for the hardest subjects. For a halo or leftover fringe, shrink the edge by a pixel and add a little feather — the local CLI exposes both as --grow -1 and --feather 1.5.

Does the free version watermark or downscale the result?

No watermark and no downscale. The output keeps the resolution of your source image, and you can export PNG, JPG or WebP.

Can I process a whole folder?

In the browser, drop several files at once and they queue up. For unattended work, point the CLI at a directory: python bg_remove.py photos/ -o cutouts/. It reports any file it cannot read and carries on with the rest.
